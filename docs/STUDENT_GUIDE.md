# Guía breve para jugar la vista previa

1. Abrir la dirección del juego facilitada por el equipo responsable y elegir una de las tres ranuras. Anotar el código `CTN` si el equipo lo solicita; no es una contraseña.
2. Leer el prólogo de tres pantallas y pulsar **Continuar** o **Enter** para avanzar. Después, mover a Sofi con **WASD** y usar **F** al acercarse a un objeto marcado. **E** abre el celular; **Tab** muestra el objetivo y pistas; **P** pausa. En el MOBA, **clic izquierdo** ataca y **Q** usa la habilidad de clase.
3. Elegir respuestas con ratón, **1/2/3** o flechas y **Enter**. Revisar la respuesta seleccionada y pulsar **Confirmar** para guardarla; **Esc** o **Volver** cancela sin elegirla. En los diálogos del Día 0, un toque revela la línea si todavía está apareciendo; cuando ya es visible, el siguiente avanza. **Historial de esta conversación** permite releer las líneas anteriores. La velocidad de lectura se ajusta desde **Pausa**. El juego guarda automáticamente y puede reabrirse en la misma ranura y navegador.
4. Si la ventana es menor de 768×448, ampliarla y pulsar **Continuar**. Si se corta la conexión, mantener los datos del navegador y usar **Reintentar sincronización** desde Pausa cuando esté disponible.

**Estado de este build:** los Días 1–4 son fragmentos de lectura en vista previa. No hay puntuación educativa visible ni recorrido narrativo definitivo. El equipo debe proporcionar un build aprobado antes de una sesión real.
